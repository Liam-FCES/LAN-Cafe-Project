# Requirements

## Functional Requirements
1. Customers can book online
2. staff can take an order alongside transaction processing
3. a database to store bookings, items, orders, and users
4. and lastly a well segmented network so wifi users cannot access admin PC's 

##  Non-Functional Requirements
1. a secure network so enforcing GPO's firewalls. etc
2. that the system and whole cafe is reliable and constantly stays running
3. and for future growth it would need to be scalable
